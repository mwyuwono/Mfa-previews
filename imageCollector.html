🎨 MFA Image URL Collector

How to use:

  1. Click on any "Open MFA Page" link below
  2. On the MFA website, right-click the artwork image → "Copy Image Address"
  3. Come back here and paste it in the input field
  4. Repeat for all artworks (or just the ones you want)
  5. Click "Export Updated JSON" when done
JSON copied to clipboard! Paste it into src/artworkData.json
